Project Overview: Developed an end-to-end data analytics project using MySQL and Power BI to analyze food delivery platform operations, customer behavior, restaurant performance, order trends, and delivery efficiency. Used SQL queries for data cleaning, validation, and analysis, and Power BI with DAX measures to create interactive dashboards and generate actionable business insights.

Tools & Technologies

MySQL: Database creation, data cleaning, joins, aggregations, and business analysis using SQL queries.

Power BI: Data modeling, interactive dashboard development, KPI visualization, and reporting.

DAX: Created calculated measures to track key performance indicators (KPIs), including total orders, revenue, average order value, and delivery performance.
